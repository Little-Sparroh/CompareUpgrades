# Changelog

## 1.0.0 (2025-10-16)

### Features
* Comparison mode for gear upgrades - press 'C' to lock/unlock upgrades for side-by-side comparison
* Automatic dual tooltip display when comparing upgrades
* Intelligent positioning of comparison tooltip to avoid overlap and screen boundaries
* Hover detection integration with existing upgrade tooltips
